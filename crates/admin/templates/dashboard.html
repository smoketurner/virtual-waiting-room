Force maintenance halts the whole room, not just admission. It moves the event to the maintenance phase and requires confirmation. Pause stops admission; this stops everything.

Phase

Move the event through its lifecycle.

The lifecycle runs forward only: idle → pre_queue → active → post_event. The server rejects a backward transition. To halt the room, use Force maintenance.

Admission rate

Visitors admitted to the origin per second.

Set this to the requests per second the origin sustains. Each unit is one visitor per second admitted. The value is a whole number from 1 to the deployment ceiling. To stop admission, use Pause; rate 0 is rejected.
