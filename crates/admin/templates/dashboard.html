Admission rate

Target visitors admitted to the origin per second.

Set this to the requests per second the origin sustains. One unit is one visitor per second. The value is a whole number from 1 to the deployment ceiling. To stop admission, use Pause; rate 0 is rejected. The admission controller ships after the MVP, so this value is stored but not yet enforced.
